Parte 2 · O padrão de publicação

A definição de pronto — para as onze satélites e para a ferramenta

Estas listas não são tarefa de um mês. Elas valem em todas as fases, e é por isso que ficam entre a análise e o roadmap: sem elas, cada fase reinventa o próprio critério de qualidade.

2.1 · Checklist SEO

  • robots.txt, sitemap e HTTPS
  • query primária definida
  • intenção definida
  • title
  • H1
  • URL
  • headings
  • meta description
  • canonical
  • conteúdo indexável
  • links internos
  • schema pertinente
  • Core Web Vitals, especialmente mobile

2.2 · Checklist AEO

  • responder perguntas diretamente
  • usar headings em formato de perguntas reais
  • criar definições curtas e objetivas
  • incluir FAQs alinhadas às dúvidas reais de busca
  • mostrar fórmulas explicitamente
  • usar exemplos numéricos
  • estruturar passos

2.3 · O que medir desde o início

Carregamento da página page_view
Interação inicial com a ferramenta tool_click
Primeiro campo preenchido tool_start
Resultado gerado tool_complete
Clique no CTA que abre o formulário lead_cta_click
Submissão válida do formulário lead_generated

Os eventos entram na Fase 1, não na Fase 4. Otimizar um funil que ninguém instrumentou é adivinhar.
